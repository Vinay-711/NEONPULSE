# Requirements Archive: v1.0

## 1. Core Workflows
- [x] Parent opens app and points camera at newborn
- [x] System tracks face/chest ROI and extracts vitals (HR/RR)
- [x] System raises immediate alert if vitals fall outside normal physiological bounds

## 2. Table Stakes (Must-Haves)
- [x] **Real-time Video Capture:** Performant camera loop
- [x] **EVM Pipeline:** Motion and color magnification for signal extraction
- [x] **Rule-based Alerts:** Thresholds for bradycardia, tachycardia, tachypnea, and apnea
- [x] **Offline Capability:** Edge inference

## 3. Differentiators
- [x] **AI Classification:** Random Forest classifier for advanced anomaly detection beyond static rules
- [x] **Zero-Hardware:** Fully software-defined monitoring

## 4. Anti-Features (Out of Scope)
- [x] Custom hardware integrations (wearables, pulse oximeters)
- [x] Cloud-dependent critical alerting (alerts must fire offline)

## 5. Technical Constraints
- [x] Real-time processing requires strict latency control (target 30fps)
- [x] Must handle varying lighting conditions and slight movement
