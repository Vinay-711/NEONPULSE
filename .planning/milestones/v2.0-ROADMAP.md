---

## Milestone Summary

**Key Decisions:**
- Decision: Fallback to PKL if ONNX unavailable (Rationale: Prevents crashes during the build/deployment pipeline if the export utility hasn't fired yet).
- Decision: Use Capacitor over React Native (Rationale: The frontend is heavily tied to standard DOM APIs like Canvas and EventSource which Capacitor wraps perfectly).
